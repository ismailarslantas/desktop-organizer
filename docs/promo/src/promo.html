Five steps. One approval.

1

Detect

Finds the real desktop — OneDrive redirects included. Asks you if anything is unclear.

2

Plan

Reads only the desktop root. 13 categories, SHA-256 duplicates, every skip explained.

3

Approve

Nothing moves until you write Planı onaylıyorum for that exact plan.

4

Start

You press Start on the local dashboard. Pause or stop at any time.

5

Undo

Every move is journaled and verified. One command puts it all back.

LIONSTONESafety first

Moves only. Never deletes.

✓

No overwrites

Same name in the target? It gets “ (2)”. Rename is atomic and refuses to replace.

✓

Folders untouched

Existing folders, shortcuts, hidden and system files stay exactly where they are.

✓

Busy files skipped

Changed in the last 15 min, still downloading, locked or cloud-only? Left alone.

✓

Same drive only

No copy-then-delete fallback. If a safe move is impossible, the file is skipped.

✓

Plan is sealed

Approval is bound to the plan’s SHA-256. Files that change after approval are not moved.

✓

Crash-safe journal

Intent and result are written for every file, and reconciled after a crash.

✓

Careful undo

Checks size, time, file id and fingerprint. An occupied spot is reported, not overwritten.

✓

Stays on your PC

No API, no telemetry, no CDN. Nothing about your files leaves the computer.
